## 🧭 About this repository

The back-end specialization track. Two threads run side by side:

- **Python's async world** — variable annotations, `asyncio` coroutines and
  comprehensions, then hypermedia pagination that survives deleted rows;
- **JavaScript's modern world** — ES6 syntax, classes and data
  manipulation, promises and async/await, Node.js HTTP servers, and a full
  Express app with controllers and a router.

The two threads meet in **MongoDB** — documents from the shell, then the
same cluster driven from Python with `pymongo` and aggregation pipelines.
